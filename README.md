# bgm-tools

YouTube の BGM チャンネル運営用の道具箱です。道具は2つあります。

| 道具 | 使う場所 | フォルダ |
|---|---|---|
| ① ワンクリック動画メーカー | 自分の Windows パソコン | `video-maker/` |
| ② 投稿記録＋次のテーマ案ページ | GitHub Pages（スマホからも見られる） | `docs/` |

---

## ① ワンクリック動画メーカー

曲と画像を入れて `run.bat` をダブルクリックすると、次の2本の動画ができます。

| 動画 | サイズ | 内容 |
|---|---|---|
| 1時間動画 | 1920×1080（横） | 画像は止まったまま。曲を1時間になるまでくり返し、最後は音がフェードアウト |
| ショート動画 | 1080×1920（縦）・25fps・33秒 | 画像がゆっくりズームイン（1.0倍→1.15倍）。上にタイトル文字。最後は音がフェードアウト |

### 準備（最初の1回だけ）

#### 1. このツールをパソコンにダウンロードする

1. ブラウザでこのリポジトリのページ（`https://github.com/bgm-maker123/bgm-tools`）を開く
2. 緑色の「**<> Code**」ボタンを押す →「**Download ZIP**」を押す
3. ダウンロードした ZIP ファイルを右クリック →「**すべて展開**」→「展開」
4. 展開してできたフォルダの中にある「**video-maker**」フォルダを、デスクトップなど分かりやすい場所に移動する

#### 2. ffmpeg（動画を作るソフト）をインストールする

1. 画面下のスタートボタン（Windows マーク）を**右クリック** →「**ターミナル**」を押す
2. 黒い（または青い）画面が開くので、下の1行をコピーして貼り付け、**Enter** を押す

   ```
   winget install --id Gyan.FFmpeg -e
   ```

3. 「同意しますか？」のように聞かれたら `Y` を入力して Enter
4. 「インストールが完了しました」と出たら、ターミナルを閉じる

> ffmpeg が入っていない状態で `run.bat` を実行した場合も、同じ手順が画面に表示されます。

### 使い方（毎回）

1. `video-maker` フォルダの中の「**input**」フォルダを開く
2. **曲（mp3）を1つ**と**画像（jpg または png）を1つ**入れる
   - 1時間動画には横長（16:9）の画像がおすすめです
   - ショートだけ別の縦長画像を使いたいときは、ファイル名に `short` か `ショート` を入れた画像も一緒に入れてください（例: `aurora_short.jpg`）
   - 前に使った曲や画像は、別の場所に移動しておいてください（名前順で最初のものが使われます）
3. `video-maker` フォルダに戻り、「**run.bat**」を**ダブルクリック**
4. 黒い画面で2つ質問されるので、答えて Enter を押す

   | 質問 | 入力の例 | 何も入力せず Enter を押すと |
   |---|---|---|
   | タイトル（ショートの上に出る文字） | `オーロラの夜空｜癒しのピアノBGM` | 曲のファイル名を使う |
   | ショートの開始位置 | `1:23`（1分23秒）または `83`（83秒） | 曲の最初から |

   - タイトルに `|`（または全角の `｜`）を入れると、そこで改行されます（3行まで）
   - 開始位置は、曲の**一番盛り上がる部分の少し前**にすると、ショートで引き付けやすくなります
5. 「完成しました！」と出るまで待つ（パソコンの性能によりますが、合計で数分ほど）
6. 自動で「**output**」フォルダが開きます。中に2本の動画ができています
   - `日付_曲名_1hour.mp4` … 1時間動画
   - `日付_曲名_short.mp4` … ショート動画
7. 黒い画面は、何かキーを押すと閉じます

### うまくいかないとき

| こんなとき | どうする |
|---|---|
| 「ffmpeg が見つかりません」と出る | 上の「2. ffmpeg をインストールする」を行う。インストール後は、開いている黒い画面をすべて閉じてから、もう一度 `run.bat` を実行 |
| 「WindowsによってPCが保護されました」と青い画面が出る | 「詳細情報」→「実行」を押す（ダウンロードしたファイルに出る注意です） |
| 「曲が入っていません」「画像が入っていません」と出る | `input` フォルダに mp3 と jpg/png が入っているか確認 |
| 画面がすぐ閉じる・文字化けする | `video-maker` フォルダの中身（`tools` フォルダも含めて）をまるごと使っているか確認。ZIP を「すべて展開」せずに中を直接開いて実行すると動きません |

### 細かい設定を変えたいとき（慣れてきたら）

`video-maker/tools/make_videos.ps1` をメモ帳で開くと、一番上に設定がまとまっています。
動画の長さ・ズームの倍率・画質などを数字で変えられます。

- 1時間動画は「静止画向けの設定」（1秒に1コマ + `-tune stillimage`）で書き出すので、ファイルが軽く、書き出しも速くなります
- タイトル文字は Windows 標準の「游ゴシック Bold」を使います（無い場合はメイリオなどを自動で使います）

## ② 投稿記録＋次のテーマ案ページ

投稿した動画の記録と、次のネタ帳をまとめたページです。スマホで見やすく、ダークモードにも対応しています。

- 投稿した動画の一覧（日付・テーマ・タイトル・フル動画URL・ショートURL・再生数・視聴維持率・学んだことのメモ）
- 「新しい順」「再生数の多い順」「視聴維持率の高い順」に並べ替え
- テーマ別の伸びが分かる棒グラフ（合計再生数 / 平均再生数 / 平均維持率 を切り替え）
- 次に作るテーマ候補
- SUNO 用プロンプトのメモ（ボタン1つでコピーできます）

### GitHub Pages で公開する手順（最初の1回だけ）

> この作業の前に、今回の変更が **main ブランチに入っている**必要があります（プルリクエストを「Merge」した状態）。

1. GitHub でこのリポジトリのページを開く
2. 上のメニューの「**Settings**」（歯車マーク）を押す
3. 左のメニューから「**Pages**」を押す
4. 「Build and deployment」の「**Source**」が「**Deploy from a branch**」になっていることを確認
5. 「**Branch**」の欄で、
   - 左のボタン → `main`
   - 右のボタン → `/docs`

   を選んで「**Save**」を押す
6. 1〜2分待ってから Pages の画面を再読み込みすると、上の方に
   「Your site is live at `https://bgm-maker123.github.io/bgm-tools/`」
   と表示されます。これがあなたのページのURLです
7. スマホでこのURLを開き、ブックマーク（またはホーム画面に追加）しておくと便利です

> **注意**: リポジトリが「Private（非公開）」の場合、無料プランでは GitHub Pages を使えません。
> その場合は Settings → General の一番下「Change repository visibility」で Public にしてください
> （Public にすると、リポジトリの中身とページは誰でも見られる状態になります）。

### データを更新する方法（GitHub のサイト上で編集するだけ）

データはすべて `docs/data.json` というファイルに入っています。

1. ページ右上の「**✏️ データを編集**」ボタンを押す
   （または GitHub で `docs` フォルダ → `data.json` → 右上の鉛筆マーク）
2. GitHub にログインしていれば、編集画面が開きます
3. 内容を書き換える
4. 右上の緑色の「**Commit changes...**」ボタン → もう一度「**Commit changes**」を押す
5. 1〜2分でページに反映されます（反映されないときはページを再読み込み）

スマホのブラウザからでも同じ手順で編集できます。

#### 動画を1本追加するとき

`"videos": [` の中に、次のかたまりを追加します。**かたまりとかたまりの間にはカンマ（`,`）が必要**です。

```json
    {
      "date": "2026-10-01",
      "theme": "雨の図書館",
      "title": "雨の図書館で読書する夜 | 作業用BGM",
      "fullUrl": "https://youtu.be/xxxxxxxxxxx",
      "shortUrl": "https://youtube.com/shorts/xxxxxxxxxxx",
      "views": 1234,
      "retention": 42.5,
      "memo": "サムネを暗めにしたら維持率が上がった"
    },
```

例えば2本目を追加すると、こうなります（1本目の `}` の後ろにカンマがあるのがポイントです）。

```json
  "videos": [
    {
      "date": "",
      "theme": "オーロラの夜空",
      ...
      "memo": ""
    },
    {
      "date": "2026-10-01",
      "theme": "雨の図書館",
      ...
      "memo": "サムネを暗めにしたら維持率が上がった"
    }
  ],
```

| 項目 | 書き方 |
|---|---|
| `date` | 投稿日。`"2026-10-01"` の形 |
| `theme` | テーマ。**同じテーマは同じ文字で書く**と、グラフでまとめて集計されます |
| `title` | 動画タイトル |
| `fullUrl` / `shortUrl` | 動画のURL。無ければ `""` |
| `views` | 再生数。`1234` のように数字だけ（`"1,234"` と書いてもOK）。分からなければ `""` |
| `retention` | 視聴維持率（％）。`42.5` のように数字だけ。分からなければ `""` |
| `memo` | 学んだこと・気づいたこと |

#### テーマ候補・SUNO プロンプトを追加するとき

```json
  "nextThemes": [
    { "theme": "雪の降る夜のカフェ", "memo": "冬に出す" },
    { "theme": "海辺の朝", "memo": "" }
  ],

  "sunoPrompts": [
    {
      "name": "オーロラの夜空",
      "prompt": "ambient piano, soft synth pads, slow tempo, calm, dreamy, instrumental",
      "memo": "テンポ遅めが合う"
    }
  ]
```

最初に入っている「（例）」の行は、書き換えても消してもかまいません。

#### 書き間違えたときは

ページの上に赤い枠で「data.json の書き方に間違いがあります → ○行目あたり」と表示されます。
その行の近くの **カンマ（`,`）の過不足** や **`"` の閉じ忘れ** を確認してください。
GitHub の編集画面の左側に行番号が表示されています。

## フォルダの中身

```
bgm-tools/
├─ README.md            … この説明書
├─ video-maker/         … ① 動画メーカー（このフォルダをパソコンで使う）
│   ├─ run.bat          … これをダブルクリック
│   ├─ input/           … 曲と画像を入れる
│   ├─ output/          … 動画ができる
│   └─ tools/           … プログラム本体（触らなくてOK）
└─ docs/                … ② 投稿記録ページ（GitHub Pages で公開）
    ├─ data.json        … ★ データはここを編集
    ├─ index.html
    ├─ style.css
    └─ app.js
```
