# ai-image-shop

AI生成画像を **DLsite / FANZA同人 / ヤフオク** で売るための準備ツールです。

- 画像フォルダから、サイトごとの **メイン画像・サンプル画像（透かし入り）・本編ZIP・説明文** をまとめて作る
- 画像に埋め込まれた **生成プロンプトやEXIFを自動で削除**
- 指定した範囲に **モザイク** をかける（1マスの大きさは長辺の1/100以上・最低4px。設定で変更可）
- 説明文に **AI使用の表記と「AI生成」タグ** を自動で入れる
- **売上を記録して、月別・サイト別に集計**（確定申告用）

アカウント登録や出品の操作はツールではできません。下の「出品までのチェックリスト」に沿って、ご自身で行ってください。

---

## 1. インストール

Python 3.11 以上が必要です。

```bash
cd ai-image-shop
pip install -r requirements.txt
```

## 2. 使い方

### 作品フォルダを作る

```bash
python shop.py init works/作品A
```

次のファイルができます。

```
works/作品A/
├── images/        ← 販売する画像を入れる（ファイル名順に並びます）
├── work.toml      ← 作品情報（タイトル・価格・使用AI・紹介文・タグ）
└── regions.json   ← モザイクをかける範囲（不要なら削除）
```

### まとめ画像を1枚ずつに切り分ける

ChatGPT などで 3×3 のように1枚にまとめて生成した画像は、コマの境目を自動で見つけて切り分けられます（コマの幅がバラバラでもOK）。

```bash
python shop.py split まとめ画像.png works/作品A/images --rows 3 --cols 3
```

`001.png, 002.png …` の連番で保存され、2回目以降は続きの番号から追加されます。
まとめ画像は1コマあたりが小さくなりがちなので、販売用には長辺 1000px 以上を目安にしてください（小さいと警告が出ます）。

### 販売用一式を作る

```bash
python shop.py package works/作品A                 # 全サイト分
python shop.py package works/作品A --site dlsite   # DLsiteだけ
python shop.py package works/作品A --cover 012.png # メイン画像を指定
```

`works/作品A/dist/作品タイトル/` に次のものが出力されます。

| ファイル | DLsite | FANZA | ヤフオク |
|---|---|---|---|
| `cover.jpg` メイン画像 | 560×420 | 560×420 | 1200×1200 |
| `samples/` サンプル（透かし入り） | 5枚 | 5枚 | 9枚 |
| `作品タイトル.zip` 本編 | ○ | ○ | なし（印刷物での出品を想定） |
| `description.txt` 説明文 | ○ | ○ | ○ |

サイズや枚数は `config/sites.toml` で変更できます。**各サイトの推奨サイズは変わることがあるので、公式ガイドで確認してから調整してください。**

### モザイク範囲の指定

`regions.json` に、元画像のピクセル座標で `[左上x, 左上y, 右下x, 右下y]` を書きます。

```json
{
  "001.png": [[100, 200, 300, 400]],
  "002.png": [[50, 60, 150, 160], [400, 420, 520, 560]]
}
```

モザイクは本編ZIP・サンプル・メイン画像のすべてに反映されます。`work.toml` で `adult = true` にしたのにこのファイルがない場合は警告が出ます。
**最終的な修正基準は各サイトの規約に従ってください。** 出力された画像は必ず目で見て確認してください。

### 説明文だけ見る

```bash
python shop.py describe works/作品A --site fanza
```

文面は `templates/*.txt` を直接編集すれば変えられます。

### 売上の記録と集計

```bash
# 1件記録（--fee には手数料・送料などをまとめて入れる）
python shop.py sales add --site dlsite --title 作品A --price 550 --qty 3 --fee 495
python shop.py sales add --date 2026-10-02 --site yahoo --title アクスタA --price 3000 --fee 520

# 集計
python shop.py sales summary --year 2026
```

記録は `sales.csv` に保存されます（Excelでそのまま開けます）。個人情報を含むので Git には含めない設定にしています。

## 3. 出品までのチェックリスト（ご自身で行う作業）

### 共通
- [ ] 使った生成AIの利用規約で **商用利用が許可されているか** 確認（モデルやLoRAごとにライセンスが違うことがあります）
- [ ] 実在の人物・既存のキャラクターや作品に似た画像を入れない（権利侵害で削除・アカウント停止の対象になります）
- [ ] 成人向けの場合は、各サイトの修正（モザイク）基準と禁止表現を確認
- [ ] 売上が出たら確定申告が必要かどうか確認（会社員の副業なら所得20万円超が目安。住民税は金額にかかわらず申告が必要です）

### DLsite
- [ ] 「サークル登録」から申請（本人確認・振込先口座を登録）
- [ ] 作品登録で **AI生成作品の区分** を選び、使った生成AIを申告
- [ ] `dist/.../dlsite/` の cover.jpg・samples・ZIP・description.txt を登録画面に入れる

### FANZA同人（DMM）
- [ ] サークル登録を申請（審査あり）
- [ ] **AI生成作品の受付条件を最新の規約で確認**（時期によって方針が変わっています）
- [ ] `dist/.../fanza/` の一式を登録画面に入れる

### ヤフオク
- [ ] Yahoo! JAPAN IDで出品者情報・本人確認を登録
- [ ] **画像データだけの出品はできない、または制限されるカテゴリがあります。** アクリルスタンド・ポスター・キャンバスなどの印刷物での出品をおすすめします
- [ ] AI生成物の表記ルールをガイドラインで確認（説明文のテンプレートには「【AI生成】」の表記を入れています）
- [ ] `description.txt` の発送方法・送料を記入してから出品
